# احضار رفیق

یک PWA فارسی برای پنج کاربر ثابت که دو پیام سریع می‌فرستند: «سیگار می‌کشی؟» و «سیگار داری؟» با پاسخ آماده «آره آره». هر نفر فقط نام خودش و دوست مقصد را انتخاب می‌کند؛ کد اتاق وجود ندارد.

## اجرای سریع

1. یک پروژه در Firebase بساز و **Realtime Database** را فعال کن.
2. در Firebase یک Web App اضافه کن و مقادیر `firebaseConfig` در `app.js` را جایگزین کن.
3. در بخش Cloud Messaging یک Web Push certificate بساز و مقدار `vapidKey` را جایگزین کن.
4. در Authentication > Settings > Authorized domains دامنه GitHub Pages را اضافه کن.
5. این پوشه را در یک repository عمومی GitHub بگذار و از Settings > Pages، شاخه `main` و پوشه `/root` را انتخاب کن.
6. هر پنج نفر نام خودشان را انتخاب کنند و برای اعلان در پس‌زمینه، روی «فعال‌سازی اعلان» بزنند. نام‌ها از آرایه `USERS` در `app.js` قابل تغییر هستند.

در حالت قبل از تنظیم Firebase، برنامه به‌صورت نمایشی در همان گوشی قابل تست است. برای نوتیفیکیشن واقعی باید Firebase تنظیم شود؛ کلیدهای واقعی را داخل repository عمومی قرار نده.
